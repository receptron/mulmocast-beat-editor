# fix: 書式を重ねると markup の区切り文字が可視テキストに漏れる (#64)

## 問題

deck の `renderInlineMarkup` は正規表現の連鎖で、**同種の入れ子を解釈できない**:

| markup | 見える文字 | 期待 |
|--------|-----------|------|
| `{warning:a{primary:b}c}` | `a{primary:bc}` | `abc` |
| `****x****` | `**x**` | `x` |

editor 側はその入れ子を平気で作っていたので、値が壊れ、次の編集はその**壊れた文字**を
書式化して、編集のたびに悪化した。

## 実測（修正前 → 修正後）

| 測定 | 修正前 | 修正後 |
|------|--------|--------|
| 単発1操作（全レンジ総当り 1375 通り） | 34 破損 | **0** |
| 同じ操作を2回（トグルで戻るか） | 282 破損 | **0** |
| 6〜8編集を積む（300〜520 シーケンス） | 291 破損 | **0** |
| 大規模ランダム（13起点 / 1040 シーケンス / 8320 編集） | — | **0** |

## 原因は3つ

1. **色の上に色を重ねると DOM が入れ子になる。** 画面上は内側が勝っているので見た目は
   変わらないが、値は `{a:x{b:y}z}` になり deck が読めない。
2. **emphasis は色と同じスロットを使う。** `*…*` は単語境界でしか書けないので
   `htmlToMarkup` は `{warning:…}` に落とす（`emReplace`）。その結果 emphasis は値の上で
   色と区別できなくなり、2回目に押しても「既に emphasis」と認識されず入れ子になった。
3. **`*` と `**` の隣接。** deck は bold を先に処理するので、`*a` の隣に `**` が来ると
   `****` が bold の区切りとして読まれる。タグ越しに隣接するため、変換時点の隣接文字
   （`<` や `>`）を見ても分からない。

## 修正

1. **色系フォーマット（色 + emphasis）を1スロットとして扱う** (`src/inlineFormat.ts`)
   - `colorOf(format)` … その書式が塗る色。emphasis は `text-d-warning` なので色扱い。
   - 適用時に `supersedeColor` が選択範囲の内側・外側の色を外してから包む。
   - トグル判定も色一致で行うので、`{warning:x}` として保存された emphasis を
     もう一度押せばちゃんと外れる。
2. **祖先に同種があれば冗長なので畳む** (`collapseNested`)
   色スパンを挟んだ `<strong>` の中の `<strong>` は画面上なにも足していないが、
   値は `**a{c:**b**}**` になって deck が誤読する。
3. **`emReplace` が bold タグの隣接を見る** (`src/editorHelpers.ts`)
   `asteriskFormSurvives` に判定を切り出し、隣に bold タグがあるときは `*…*` を使わない。

`removeFormat` は「1つの書式」ではなく **matcher** を取るようにした。`clearFormat` は
`() => true` を渡すだけになり、`liftPast` の早期 break（元コメントいわく出力に影響しない
最適化）も落とせたので、分岐が1本減っている。

## テスト

`test/test_formatRoundTrip.ts` を新設。既存の書式テストは**すべて「1回の編集」で終わって
いて、編集結果を再レンダリングして再度編集するサイクルが一つも無い**のが、この欠陥を
通した理由。

1. 起点の健全性（sweep が deck の限界ではなく editor を測っていること）
2. 単発1操作 × 全レンジ総当り 1375 通り
3. 同じ操作を2回かけて元に戻ること
4. ランダムな 8 編集 × 520 シーケンス（引用符・日本語・多色を含む13起点）
5. deck が読めない形／読める形を明示的に固定

### break-check

| 変異 | 結果 |
|------|------|
| `supersedeColor` の呼び出しを削除 | 98 単発 + 218 トグル + 241 サイクルが赤 |
| `emReplace` の bold 隣接判定を無効化 | 20 単発 + 7 サイクルが赤 |
| `emReplace` の `*` 端判定を無効化 | 10 サイクルが赤 |
| `collapseNested` を直接の親だけに戻す | 14 サイクルが赤 |
| すべて戻す | 5/5 green |

## 既知の残課題（このPRの範囲外）

ユーザーが本文に `**` や `{primary:` を**文字として入力**した場合のエスケープが無い。
そういう値は deck 側でそもそも解析できず、編集すると文字が消える。issue #64 に記録済み。
